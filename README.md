# ترب‌بلیت

رابط فارسی و راست‌چین برای جست‌وجو و مقایسهٔ پرواز. ترب‌بلیت فروشندهٔ بلیت نیست و قیمت، ظرفیت یا موجودبودن نرخ را هنگام خرید تضمین نمی‌کند.

## داده‌ها و محدودیت‌ها

- جست‌وجوی محصول فقط snapshotهای واقعی Safarmarket را از `data/crawl/` می‌خواند؛ دادهٔ برنامهٔ آزمایشی یا fixture به کاربر نمایش داده نمی‌شود.
- بدون snapshot سازگار با مسیر و تاریخ، نتیجه خالی می‌ماند و صفحه راهنمای مشاهدهٔ وضعیت در `/crawl` را می‌دهد.
- رابط و API جست‌وجو crawler یا درخواست زنده به فروشنده اجرا نمی‌کنند. جمع‌آوری داده عملیاتی جداگانه است و فقط با دستور صریح CLI/worker انجام می‌شود.
- snapshot قیمت را در زمان ثبت نشان می‌دهد؛ این برنامه خرید یا موجودی کنونی را تأیید نمی‌کند.
- جدول برنامهٔ پرواز در `src/lib/schedules.ts` صرفاً برای توسعه و تست است: بیش از ۱٬۱۰۰ برنامهٔ پرواز، ۱۳۷ مسیر، ۴۷ شهر، ۲۵ ایرلاین و مسیرهای غیرتهرانی دارد. این اعداد پوشش واقعی فروش یا نرخ نیستند.
- کاتالوگ لوگو ۲۵ ایرلاین را پوشش می‌دهد؛ از جمله معراج و مهر. برای دارایی‌های با مجوز نامشخص باید پیش از استفادهٔ تجاری مجوز صاحب برند بررسی شود.

## شروع سریع

نیازمندی: Node.js سازگار با Next.js 15 و npm.

```bash
npm ci
npm run dev
```

برای اجرای صفحهٔ نتایج واقعی، باید snapshot معتبر محلی برای مسیر و تاریخ موردنظر موجود باشد. فایل‌های `data/crawl/` محلی‌اند و commit نمی‌شوند. راهنمای جداگانهٔ اپراتور crawler در [`docs/CRAWLER.md`](docs/CRAWLER.md) است.

## آزمون و ساخت

```bash
npm run typecheck
npm run lint
npm test
npm run build
```

برای اجرای production پس از ساخت:

```bash
npm start
```

## حریم داده و تنظیمات

`.env.example` فقط نام تنظیمات اختیاری و placeholder دارد. هرگز `.env`، رازها، پاسخ‌های خام محرمانه یا محتوای `data/crawl/` را در Git ثبت نکنید. سیاست داده و محدودیت‌های محصول در [`docs/COMPLIANCE.md`](docs/COMPLIANCE.md) و وضعیت دموی محلی در [`docs/DEMO.md`](docs/DEMO.md) آمده است.

# اجرای دموی محلی

این راهنما برای نشان‌دادن رفتار واقعی رابط است؛ دادهٔ نمونه به‌عنوان نرخ پرواز نمایش داده نمی‌شود.

## اجرا

```bash
npm ci
npm run dev
```

صفحهٔ اصلی و مسیرهای فرم را می‌توان بدون دیتابیس یا کلید LLM باز کرد. برای مشاهدهٔ نتیجه در `/search` باید snapshot واقعی Safarmarket برای همان مسیر و تاریخ در `data/crawl/` موجود باشد. اگر snapshot موجود نیست، پیام خالی و لینک `/crawl` نشان داده می‌شود؛ این رفتار عمدی است و نباید با fixture یا جدول برنامهٔ آزمایشی پر شود.

## چه چیزی را نشان دهیم

1. صفحهٔ اصلی فارسی، فرم مسیر، تقویم شمسی و ورودی زبان طبیعی را مرور کنید.
2. جست‌وجوی مسیری را باز کنید که snapshot واقعی محلی و پاک‌سازی‌شده دارد. اگر چنین داده‌ای در محیط دمو موجود نیست، همان حالت خالی را نشان دهید.
3. در صفحهٔ `/crawl` وضعیت snapshotهای محلی را ببینید. این صفحه فقط می‌خواند؛ آغاز crawl نیازمند اجرای صریح اپراتور از CLI است.
4. در صورت وجود نرخ‌ها، توضیح دهید snapshot مربوط به زمان ثبت است و خرید/ظرفیت کنونی را تضمین نمی‌کند.

## دادهٔ توسعه و تست

`src/lib/schedules.ts` و `src/providers/fixtures.ts` برای تست و توسعه باقی مانده‌اند؛ این‌ها منبع نرخ واقعی نیستند. تست‌های رابطی که به سناریوهای غنی احتیاج دارند، fixture را پشت mock تستی استفاده می‌کنند. این داده‌ها نباید در build یا پاسخ محصول ظاهر شوند.

## اجرای crawler

راهنمای عملیاتی و شروط اجرای مجاز در [`CRAWLER.md`](CRAWLER.md) آمده است. هر اپراتور باید منبع، مسیر، تاریخ و مجوز دسترسی را خودش تأیید کند. خروجی واقعی در `data/crawl/` محلی می‌ماند و نباید به مخزن اضافه شود.

## آنچه این دمو اثبات نمی‌کند

- دسترسی کنونی به Safarmarket یا قابلیت خریدن نرخ؛
- تازگی، کامل‌بودن یا پوشش همهٔ مسیرها؛
- وجود آرشیو واقعی Safarmarket در clone تازه؛
- پیکربندی production یا موفقیت درخواست‌های واقعی crawler.
